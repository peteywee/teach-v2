## 1. OQ-SYS-1 — precedence inside a contract group (SYS-4)

Owner-supplied: contracts in a group are **peers**; numeric order confers no precedence; on conflict the **more restrictive** requirement applies and the conflict is **recorded**.

Proposed SYS-4 text: "Contracts within one group are peers. Numeric order MUST NOT be read as precedence. When two peer requirements conflict, the more restrictive requirement governs and the conflict MUST be recorded in `governance/conflict-register.json` with both requirement IDs, the governing choice and a resolution issue."

"More restrictive" test: the requirement that permits fewer states, actors, data flows or effects. When restrictiveness cannot be ordered (each forbids something the other allows), both restrictions apply; if both cannot be satisfied at once, the operation fails closed (SYS-9) and the conflict blocks implementation until a revision resolves it.

## 4. OQ-CNT-2 — customer content approvals (CNT-11) — split

Registers now (owner-supplied mechanism): approvals live in a Content-owned append-only record bound to `(content_pack_id, content_version, content_digest)`, written only by an actor holding a content-approval capability in the customer organization's scope, recording actor, organization, timestamp and audit in the same transaction. A new content version never inherits an approval. Withdrawal is a new record, not an update.

Residual: **who** may approve (role/title in the customer organization). Until supplied, no approval record can be written and CNT-11 holds: content displays and records no customer-approval claim. OQ-CNT-1 (versioning) is already resolved, so the recorded dependency is satisfied.

Owner-supplied: **WCAG 2.2 Level AA.** WEB-15 additionally requires controls of at least 44×44 CSS px, which is stricter than WCAG 2.2 SC 2.5.8 (24×24); the stricter value governs (SYS-1 restrictive rule).

| Automated | axe-core run on each core path state (loading, error, empty, forbidden, success) | Zero violations at `wcag2a`, `wcag2aa`, `wcag21aa`, `wcag22aa` tags |
| Keyboard | Manual script per core path | Every action reachable; visible focus (SC 2.4.11 not obscured); no trap |
| Screen reader | VoiceOver (iOS Safari) and TalkBack (Android Chrome) per core path | Each control announced with role and name; WEB-9 forbidden heading receives focus |

Automation supplements manual checks; it never replaces them.
